About

Hi, I’m Mohammad Sadique Iqbal, a passionate DevOps Engineer with hands-on experience in cloud platforms, automation, and CI/CD pipelines. I specialize in deploying and managing applications on AWS, Digital Ocean, and containerized environments using Docker and Kubernetes. During my time at Big Oh Notation Pvt. Ltd., I worked on real-world projects where I deployed applications as Kubernetes clusters, containerized applications, and configured cloud services like Redis, Kafka, WordPress, and MySQL. Earlier, as a Server Administration Intern at Netcamp Solutions, I gained practical experience in setting up Linux servers, configuring mail and DNS servers, and hosting websites.

I enjoy building automation pipelines that ensure smooth integration and deployment. Some of my projects include:

  • A Python-based monitoring and alerting system integrated with Jenkins CI/CD.
  • A CI/CD pipeline for static website deployment using GitHub Actions, AWS EC2, and Nginx.

Apart from DevOps, I also have skills in web development (HTML, CSS, JS), server configuration, and scripting in Bash and Python. I’m always eager to learn, solve problems, and take on new challenges in the ever-evolving DevOps and cloud ecosystem. When I’m not working with servers and pipelines, you’ll probably find me in a restaurant or exploring new tech.
